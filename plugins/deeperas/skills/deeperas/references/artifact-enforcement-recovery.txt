ARTIFACT ENFORCEMENT AND RECOVERY
Procedural plans need enforcing construction AND concrete recovery, not checks alone. State initial state, repetition/separator counts, first/last boundaries, stopping conditions. Linear sequences separated only between neighbors need N-1 separators for N units, none after the last.
Layouts: numeric maximum width AND height; preserve proportions fitting BOTH; explicit numeric sum of simultaneous content/gaps within usable space. State controls enforcing EVERY allowance: first-unit extras, positioning, text wrapping/line/height limits, line/paragraph spacing. Arithmetic alone does not enforce fit. Repairs: shrink flexible elements/spare spacing, have authors shorten their own overflow, remove only unintended empty units/separators, retaining required content/order/count.
After conversion check EVERY unit against EVERY exact criterion; repair editable source, re-export, repeat complete checks UNTIL all pass. Resolve delegated construction details, including exact text unless user-owned, without interview; real conflicts use rule 0/ASK or answer-now limits, never silent relaxation. Execute/inspect artifacts only when authorized; plans are not execution evidence.
